# کتابخانهٔ اجزای مرجع مشعل

۳۸ کامپوننت مستقل از هفت تصویر ارسالی R01 تا R07، برای تغییر ظاهر مشترک صفحات بدون دست‌زدن به محاسبات و دیتابیس.

## شروع

از ریشهٔ مخزن:

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory ui-kit/mashal-reference
```

روی همان رایانه، آدرس `http://127.0.0.1:4173` را باز کنید. این آدرس لینک عمومی اینترنتی نیست. فایل index.html به HTTP نیاز دارد، چون نمونه‌ها و کاتالوگ را با fetch محلی می‌خواند. هیچ npm، .NET یا دیتابیس برای نمایش کتابخانه لازم نیست.

گالری امکان جستجو، تغییر پوسته، نمایش حالت غیرفعال و خطا، مقایسهٔ برش مرجع با جزء زنده و کپی HTML را دارد. در «اندازهٔ اصلی»، هندسهٔ جزء بدون کوچک‌نمایی دیده می‌شود. برای آزمایش واکنش‌گرایی، به آدرس specimen عبارت `&responsive=1` اضافه کنید؛ نمونه‌های پیش‌فرض برای مقایسه با تصویر، حالت دسکتاپ مرجع را در iframe باریک هم حفظ می‌کنند.

## ساختار

| فایل یا پوشه | کاربرد |
|---|---|
| `tokens.css` | منبع مرکزی رنگ‌ها، فونت، اندازه‌ها، فاصله‌ها و دو پوسته |
| `components.css` | ظاهر اجزای مستقل با پیشوند `mr-` و فعال‌سازی اختیاری |
| `behaviors.js` | تعامل نمایشی؛ بدون ثبت، محاسبهٔ پول، storage یا درخواست شبکه |
| `adapter.css` | اتصال اختیاری ظاهر به کنترل‌های واقعی Razor موجود |
| `templates/C01.html` تا `C38.html` | HTML جداگانهٔ هر جزء |
| `catalog.json` | مرجع، crop، مقیاس، اندازه و محدودیت هر جزء |
| `references/` | هفت تصویر اصلی بدون تغییر و با SHA256 در کاتالوگ |
| `reference-crops/` | برش تحلیلی واقعی هر کامپوننت |
| `assets/` | فونت و آیکن‌های موجود پروژه، لوگوی مشعل و برش دارایی‌های تصویری مرجع |
| `qa/` | تصویر مرورگر هر جزء، مقایسهٔ کنارهم و نتایج بررسی تعامل |
| `INTEGRATION.fa.md` | اتصال مرحله‌ای به shared partialهای واقعی مشعل |

## قرارداد استفاده

```html
<link rel="stylesheet" href="assets/bootstrap-icons.min.css">
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="components.css">
<section data-mr-theme="light">
  <!-- HTML کامپوننت انتخاب‌شده -->
</section>
<script src="behaviors.js"></script>
```

مقدار theme می‌تواند `light` یا `blue` باشد. هیچ استایلی خارج از این ریشه فعال نمی‌شود. مسیر assetها را متناسب با محل نصب تنظیم کنید. هر نمونه مستقل است؛ خود کارت، فهرست و فرم از اجزای کوچک‌تر همین کتابخانه ساخته شده‌اند.

## دقت و حدود استخراج

- رنگ‌های آبی از پیکسل‌های R05 نمونه‌برداری شدند: زمینهٔ آبی `#007db2`، انتخاب منو `#006088`، دکمه و خط مودال `#0080e2`. زمینهٔ گزینهٔ ابزارک `#e8e8e8` و آیکن تیره `#200e32` از R06 است.
- هندسهٔ R05/R06/R07 برش مستقیم است؛ مثلاً کارت شخص ۹۴۲×۱۴۵، گروه کارت ۱۰۰۸×۲۱۱، ابزارک ۴۵۷×۳۶۸ و مودال ۶۵۲×۴۶۹ پیکسل. مقدار box از مرورگر هم در qa/browser-checks.json ذخیره شده است.
- R01 تا R04 فایل JPEG کوچک‌شده‌اند. مقیاس CSS آن‌ها برآورد کالیبره‌شده است، نه اندازه‌گیری قطعی zoom و DPR اولیه. کادرهای آبی/قرمز آموزشی روی تصاویر جزو جزء کدنویسی‌شده نیستند.
- فایل اصلی آواتارها و آیکن‌های ابزارک در دسترس نیست. آن‌ها از خود screenshot استخراج شده‌اند؛ وضوح بالاتر ادعا نمی‌شود. سایر آیکن‌ها از Bootstrap Icons موجود در پروژه‌اند و ممکن است با منبع اصلی متفاوت باشند.
- فونت نمونه‌ها IRANSans موجود پروژه است؛ هویت فونت داخل تصاویر اثبات نشده است. یکسانی کامل glyph و antialiasing ادعا نمی‌شود.
- لوگو و متن‌های هویتی عمداً مشعل‌اند. متن و رقم نمونه از مرجع یا نام مشعل است؛ هیچکدام دادهٔ واقعی یا محاسبهٔ مالی نیستند.
- پایین کارت بانک R07 بریده شده؛ حالت‌های hover، خطا، focus، loading و موبایل کامل در مرجع دیده نمی‌شوند. موارد پیاده‌شدهٔ تکمیلی، استخراج قطعی از عکس محسوب نمی‌شوند.
- در جدول R04 فقط سرستون دیده می‌شود؛ طراحی بدنه و صفحه‌بندی از این تصویر قابل اثبات نیست.
- «۱۰۰ درصد» برای تمام متن‌ها، آیکن‌ها و حالات ادعا نمی‌شود. این بسته یک کتابخانهٔ قابل‌اندازه‌گیری با شواهد و محدودیت‌های ثبت‌شده است. برای تطابق کامل، فایل طراحی، فونت اصلی و دارایی‌های اصلی لازم‌اند.

## اتصال به نسخهٔ فعلی production

[راهنمای اتصال](INTEGRATION.fa.md) نقاط واقعی Shared، قرارداد حفظ binding و مسیر اجرای تدریجی را توضیح می‌دهد. این بسته به ۱۵ migration یا commitهای مالی نسخهٔ جدید وابسته نیست؛ فقط پوشهٔ کتابخانه را منتقل کنید. هیچ تغییری در runtime سیستم یا سرور به‌صورت خودکار فعال نشده است.

## بررسی مجدد

ابزارهای QA به Python، Pillow و Playwright/Chromium نیاز دارند؛ runtime کتابخانه این وابستگی‌ها را ندارد.

```bash
cd ui-kit/mashal-reference
python3 tools/build_catalog.py --references references
python3 tools/verify_browser.py --base-url http://127.0.0.1:4173/
```

بررسی‌ها شامل همهٔ ۳۸ تصویر، جستجو، پوسته، حالت خطا/غیرفعال، انتخاب همه، مودال و Escape/بازگشت focus، stepper، افزودن/حذف کارت نمایشی، disclosure، موبایل و خطاهای مرورگر است. گزارش latest در `qa/design-qa.md` است.

فونت IRANSans تحت مجوز موجود پروژه است؛ فایل مجوز در assets حفظ شده است. تصاویر مرجع و دارایی‌های بریده‌شده از همان فایل‌های ارسالی کاربر آمده‌اند؛ مجوز جدید یا مالکیت آن‌ها ادعا نمی‌شود.
